    3. 제휴 링크 확정

    키워드마다 홍보할 카카오 선물하기 상품을 고르고 확정합니다. 확정한 링크로 4단계 문구를 만듭니다.

    상품이 겹쳐 후보에서 빠진 키워드 개

      같은 링크를 여러 키워드로 반복 홍보하지 않도록 뺐습니다. 이 키워드도 쓰고 싶으면 🎁 카카오 상품에서 관련 상품에 태그를 넣어 후보를 늘려 주세요.

      2단계 분석이 새로 실행되었습니다. [후보 만들기]를 눌러 최신 결과로 다시 만드세요.

      ※ 링크가 살아 있는지 확인하려고 프로그램이 링크를 직접 열지는 않습니다. 내 제휴 링크를 직접 누르면 클릭 수가 늘어 큐레이터 실적 통계가 왜곡될 수 있어, 형식만 확인합니다. 상품 확인은 '상품 페이지'로 하세요.

      링크 후보

      확정키워드홍보할 상품가격제휴 링크 (4단계 문구에 자동 입력)

      ⚙ 시스템 설정

      🎁 카카오 선물하기 큐레이터 상품

      크롬으로 선물하기에 로그인 → 큐레이터 → 상품별 [링크 생성]을 눌러 링크를 모읍니다. 모은 상품은 2단계 매칭에 자동으로 쓰입니다.
